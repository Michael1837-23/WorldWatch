## 1. 功能定义

新增「新闻过滤」，两种模式：

- **全部新闻**（默认）：与现在完全一致。
- **个性新闻**：同时满足下面的规则才显示。

个性新闻的规则（用户已确认四种方式都要）：
1. **按领域**：在 8 个 `NewsCategory` 中勾选想看的，默认全选。
2. **按来源**：在 `NewsSource.all` 中勾选想看的，默认全选。注意它和现有的「来源」开关不同：现有开关是**停止抓取**；这里只是**不显示**，数据照常抓取，地图冲突染色等仍然使用。
3. **关注关键词**：用户输入的词。标题含关注词的新闻**一定显示**，即使它的领域或来源没被勾选（屏蔽词优先级更高，见第 4 条）。另提供开关「只看含关注关键词的新闻」：打开后只显示命中关注词的新闻，忽略领域和来源勾选。
4. **屏蔽关键词**：标题含屏蔽词的一律不显示，优先级最高。

判定可以写成：
```
show = !blocked && (followOnly ? followed : (followed || (categoryChosen && sourceChosen)))
```

关键词匹配规则：
- 同时匹配原文 `title` 和译文 `translatedTitle`，这样中文关键词也能匹配到已翻译的英文新闻，英文关键词也能匹配英文原文。
- 不区分大小写；简繁体都要能匹配（例如用 `StringTransform("Traditional-Simplified")` 把两边都转成简体再比较）。
- **纯 ASCII 的关键词按单词边界匹配**，避免 `AI` 命中 `said`、`US` 命中 `virus`；含中文的关键词按子串匹配。
- 关键词去掉首尾空白、去重，空词忽略。每类最多 50 个。

## 2. 作用范围

- **作用于**：App 主窗口新闻列表的所有范围（综合、最新、国内、国际、各领域、灾害），列表右上的条目数；「世界动态」新闻组件；「世界总览」组件右侧新闻列。
- **不作用于**：地图的冲突染色、地震／灾害标记、台风、城市实景；新闻抓取与翻译（翻译优先级可以保持现状）。
- 顺序：先过滤，再去重、排序，然后应用国内占比上限（`balancedByOrigin`），最后截取条数。综合模式（`digestPool`）也先过滤。
- 过滤后为空时：新闻组件显示 `note` 文案「没有符合个性设置的新闻」；App 列表用现有 `ContentUnavailableView` 样式，标题「没有符合条件的新闻」，按钮「调整过滤」打开设置窗口。

## 3. 数据与持久化

- 新增一个 `NewsFilter`（`Codable`、`Sendable`、`Equatable`），包含：模式、选中的领域、选中的来源 ID、关注词、屏蔽词、只看关注词开关。整体以 JSON 存进 App Group 偏好（键如 `newsFilter`），App 与组件共享，读取写法参考 `DomesticShare.selected`。
- 选中集合**用「排除集」存储**（存没勾选的领域和来源），这样以后新增来源或领域时默认是选中的。
- 提供纯函数 `func newsFilterAllows(_ event: WorldEvent, filter: NewsFilter) -> Bool` 和 `func applyNewsFilter(_ events: [WorldEvent], filter: NewsFilter) -> [WorldEvent]`，便于测试。关键词的正则或规范化结果可以在 `NewsFilter` 里懒计算或缓存，避免每条新闻重复编译正则。
- 修改任何过滤设置后：调用 `publishWidgetSnapshot(forceReload: true)`（它会重载所有组件 kind），App 列表立即刷新。

## 4. 界面

### 4.1 设置窗口（`SettingsView`）
在「小组件」分组之后新增「新闻过滤」分组，风格与现有 `Form(.grouped)` 一致：
- 分段选择器：全部新闻 ／ 个性新闻。
- 选择「个性新闻」时才显示下面的内容（选择「全部新闻」时折叠，但保留已填的设置）：
  - **领域**：8 个开关。可以用两列紧凑排布，但必须是原生 `Toggle`。
  - **来源**：`DisclosureGroup`「来源（已选 N/M）」，展开后每个来源一个开关，顶部提供「全选」「全不选」两个按钮。被现有「来源」开关停止抓取的来源要标注「已停止抓取」，并且不可勾选。
  - **关注关键词**：输入框加「添加」按钮（回车也能添加）；已添加的词显示为可删除的小标签（胶囊样式，点 × 删除），标签自动换行。下方开关「只看含关注关键词的新闻」。
  - **屏蔽关键词**：交互同上。
  - footer 说明：「关注关键词会让对应新闻始终显示；屏蔽关键词优先级最高。过滤只影响新闻列表和新闻组件，不影响地图。」
